    How to read this

    Each bar is one session cut into agent runs. A run's color is what the human contributed at the handoff that started it, or its free-form label. Solid runs follow handoffs where the agent could have kept going without the human. Faded runs follow handoffs where it genuinely needed them. White ticks inside a run are mid-run handoffs (permission prompts, questions, plan approvals).

    Labels and findings were written by the agent from the transcripts. Run times come straight from timestamps and include command runtime.
