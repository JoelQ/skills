      How each kind of work ended

      Runs counted by what they were for and why they stopped. Red columns are forced stops. Select a cell to find those runs on the map.

      How this was made

      A script cut each transcript into runs. Compactions, subagent results, background notifications and commands auto mode refused all stay inside a run. A run ends only when you had to act, so time spent waiting on a background task counts as part of the run. Whether a stop was forced comes from the logs too: a permission prompt, an interrupt, or an auth or login error just before the agent gave up.

      Claude then named what each run was for, using the run before it, where the run's tool calls went, and what you asked. Colour shows the family of that label; hover a run for the label itself. Hatched runs are labels it was unsure of. It drew brackets from the shape of the runs, named them from a shared vocabulary, and wrote its read separately. Bar widths are scaled within each session.
